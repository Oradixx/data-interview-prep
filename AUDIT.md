# Audit des questions (novembre 2026)

Audit des 118 questions de `data/questions/*.json` (bonne réponse et explication) contre la
documentation officielle, dans les versions publiées au 4 novembre 2026 : PostgreSQL 18 (18.6),
Spark 4.3.0, Kafka 4.4.0, Airflow 3.3.2, MLflow 3.17.2, scikit-learn 1.9.1, Git 2.56, et la
documentation Docker et Kubernetes (branche `main` du 3 novembre 2026).

**Résultat.** Aucune bonne réponse n'était fausse : aucun index `answer` et aucun ordre `steps`
n'a changé. 14 questions ont été corrigées : 14 explications, plus 2 options et 1 énoncé
reformulés pour qu'ils restent exacts. 11 corrections sont vérifiées sur la source de la doc,
3 sont marquées « non vérifié en ligne ».

## Méthode

- Le réseau de cette session bloque les sites de documentation : postgresql.org,
  spark.apache.org, kafka.apache.org, airflow.apache.org, mlflow.org, docs.docker.com,
  kubernetes.io, git-scm.com, docs.aws.amazon.com, aws.amazon.com, docs.cloud.google.com,
  platform.openai.com, kimballgroup.com.
- À la place, j'ai lu **les fichiers source de ces pages** dans les dépôts officiels des projets,
  au tag de la version publiée (par exemple `apache/spark@v4.3.0`, `docs/sql-performance-tuning.md`).
  C'est le texte à partir duquel la page est générée. Dans la colonne « Vérification », cela
  s'écrit « source de la page lue ».
- Une seule page web s'est ouverte directement : la documentation Anthropic sur le tool use.
- **non vérifié en ligne** veut dire que je n'ai pu ouvrir ni la page ni sa source. La correction
  repose alors sur mes connaissances et doit être relue.
